The apps aren't in the Play Store yet, so you download them from our website. It takes a couple of minutes.

## Install an app

1. On your phone, open **ah-ha.app/android**.
2. Tap **Download** next to the app you want.
3. If Chrome warns about the file, tap **Download anyway**.
4. Open the downloaded file. If Android says it isn't allowed to install apps from this source, tap **Settings**, turn on **Allow from this source**, and go back.
5. Tap **Install**. If Play Protect says it doesn't recognize the app, tap **More details**, then **Install anyway**.

You can switch **Allow from this source** off again afterwards. You only need it when you install or update.

## Updating an app

Download the new version from the same page and install it over the old one. **Don't uninstall first.** Ah! Rhythm and Ah! Cart keep their information on your phone, and uninstalling erases it.

If Android says **"App not installed"**, see [[troubleshooting|Troubleshooting]].
